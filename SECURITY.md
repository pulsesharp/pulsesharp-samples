# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub instead: go to the **Security** tab of this repository and choose **Report a vulnerability**. A problem in PulseSharp itself can be reported the same way in the [PulseSharp repository](https://github.com/pulsesharp/pulsesharp/security).

You will get a reply within 7 days.

## About the samples

The samples show how to use PulseSharp. They are not meant to run as they are in production: the till keys, the database password and the admin settings in the code and in `appsettings.json` are demo values. Use real secrets and HTTPS in your own app.
